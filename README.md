## Data Processing Logic

The solution analyses telemetry data collected from offshore wind turbines.

Each turbine is evaluated against the following anomaly rules:

- Average Temperature > 85°C
- Maximum Vibration > 15 mm/s

Any turbine exceeding either threshold is flagged as requiring maintenance.

---

## Python Solution

The script:

1. Loads telemetry data from a CSV file
2. Groups records by turbine ID
3. Calculates average temperature
4. Calculates maximum vibration
5. Applies anomaly detection rules
6. Outputs a list of turbines requiring maintenance

### Example Code

```python
import pandas as pd

data = pd.read_csv("telemetry_data.csv")

summary = data.groupby("turbine_id").agg({
    "temperature": "mean",
    "vibration": "max"
}).reset_index()

failing = summary[
    (summary["temperature"] > 85.0) |
    (summary["vibration"] > 15.0)
]

print("Failing Turbines:")
print(failing["turbine_id"].tolist())
```

## Engineering Report Summary

The solution identifies turbines that exceed safe operating thresholds and require urgent maintenance attention.

A scalable cloud architecture is proposed to replace the legacy system. Incoming telemetry data is buffered through a message queue before being processed in real time. Recent data is stored in a high-performance time-series database, while historical data is stored within a data lake for long-term analysis.

This approach increases reliability, supports future growth, enables predictive maintenance, and reduces operational risk.
